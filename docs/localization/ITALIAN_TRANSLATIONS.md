# Sorting Puzzle — Italian Translations

Locale: `it` · Prepared October 5, 2026

Italian translations of all **251 inventory entries**, with the original English and keys for review. The six entries marked as plural-sensitive have singular and plural variants in the appendix. The main tables use plural wording for those entries.

The translations use informal, friendly Italian. Placeholders (`%d`, `%s`), all-caps titles, symbols, and the source inventory's escaped line-break notation are preserved. `AD`, `OFF`, and the current app name `SortingPuzzle` remain unchanged; discount tags retain the original percentage followed by `OFF`. Player names, email addresses, reference codes, and prices supplied through placeholders remain unchanged.
