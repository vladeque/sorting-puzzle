Locale: `pt_BR` · Prepared October 6, 2026

Brazilian Portuguese translations for all 251 keyed strings in **Sorting Puzzle — Translation String Inventory.md**, including the October 5 copy update. English is retained alongside each translation for review.

The main tables show the plural version when a count varies. Seven singular/plural pairs appear below, including the six flagged in the inventory and the weekly coin reward tooltip. The CSV has one row per original key, with columns for the main translation, singular version, context and notes.

Formatting: `%d` and `%s` are unchanged and stay in their original order. Visible `\n` markers represent forced line breaks; `\n\n` separates paragraphs. The CSV stores these as actual line breaks inside quoted fields. All-caps headings remain in caps.

The compact markers `AD` and `OFF`, dynamic discount percentages, and the brand names SortingPuzzle / Sorting Puzzle retain their original spelling. Language names, email addresses, reference codes and player names remain unchanged when inserted into the text.

- Durations use **d**, **h**, **min** and **s**. Date values inserted into `%s` should use Brazilian Portuguese, for example **2 de novembro de 2026**.
- Deletion warnings explicitly retain **Nada foi excluído** and **Esta ação não pode ser desfeita**. The 30-day removal period is unchanged.
